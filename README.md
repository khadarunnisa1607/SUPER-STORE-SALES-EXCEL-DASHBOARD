Excel-based sales analysis and interactive dashboard using the Superstore dataset.

Project Overview

This project analyzes the Superstore retail dataset to surface sales, profit, and performance trends for business stakeholders — built as a fully interactive Excel dashboard with live filtering, no manual formula changes required.

# Tools Used
Microsoft Excel — PivotTables, PivotCharts, Slicers.

# Key Results
1) $2.29M total sales across 5,009 orders.
2) 12.47% profit margin, $458.52 average order value.
3) Technology is the strongest category by both sales and profit.
4) Furniture shows comparatively thin margins relative to its sales volume.
5) East and West regions are the strongest performers; South is weakest.

# Dashboard Features
1) 5 KPI cards: Total Sales, Total Profit, Total Orders, Average Order Value, Profit Margin.
2) Monthly sales trend — line chart tracking sales over time.
3) Sales vs. Profit by Category — comparison bar chart.
4) Sales by Region — regional performance breakdown. 
5) Top 10 Products — ranked by sales volume.
6) 4 interactive slicers: Region, Category, Ship Mode, Segment — filter the entire dashboard live.

# Process
1) Cleaned and structured the raw sales dataset.
2) Built PivotTables to compute KPIs and category/region breakdowns.
3) Designed 4 PivotCharts (trend, category comparison, regional, top products)
4) Added slicers across Region, Category, Ship Mode, and Segment for live, formula-free filtering across the whole dashboard.
